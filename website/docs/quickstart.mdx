# Quickstart

Run PullMD on your machine with Docker and convert a page. You need Docker with the Compose plugin. Nothing else to configure: every setting has a working default.

<Steps>
  <Step title="Download the compose file">
    ```bash
    mkdir pullmd && cd pullmd
    curl -O https://raw.githubusercontent.com/AeternaLabsHQ/pullmd/main/docker-compose.yml
    ```
  </Step>
  <Step title="Start PullMD">
    ```bash
    docker compose up -d
    ```

    This starts PullMD and its three helper containers (Trafilatura, Playwright and MarkItDown). The first start downloads about 1.4 GB of images and uses about 5 GB of disk, most of it the headless browser.

    <Tip title="Port 3000 in use">If port 3000 is taken, create a `.env` file next to the compose file with `PORT=3080` (or any free port) and run the command again.</Tip>

    The compose file sets fixed container names, so a second copy of it fails with a name conflict. To run another instance, see [Run a second instance](/self-hosting/installation#run-a-second-instance).
  </Step>
  <Step title="Check that it's healthy">
    ```bash
    curl http://localhost:3000/api/status
    ```

    Until the server is ready, the request fails to connect. To wait for it, repeat the request until it returns HTTP `200`:

    ```bash
    until curl -sf http://localhost:3000/api/status; do sleep 1; done
    ```

    When it is ready, the response looks like this:

    ```json
    {"ok":true,"version":"3.22.0","services":{"trafilatura":{"status":"ok","latencyMs":70},"playwright":{"status":"ok","latencyMs":49},"markitdown":{"status":"ok","latencyMs":55}}}
    ```

    <Check title="Healthy response">You should get `"ok": true` and each sidecar listed as `"status": "ok"`. If a sidecar is `down`, the request returns HTTP `503`; a sidecar that isn't set up shows `not-configured`.</Check>
  </Step>
  <Step title="Convert a page">
    ```bash
    curl "http://localhost:3000/api?url=https://en.wikipedia.org/wiki/Markdown"
    ```

    You get the article as Markdown: a `# Title` line, then the content. No navigation, no scripts. Every conversion also gets a share link; see [Share links and cache](/guides/share-links).
  </Step>
  <Step title="Ask a question">
    To get only the sections that answer a question, add `query`:

    ```bash
    curl "http://localhost:3000/api?url=https://en.wikipedia.org/wiki/Markdown&query=who+created+markdown"
    ```

    The response headers say how much was cut: `X-Extract-Original-Tokens` and `X-Extract-Returned-Tokens`. Both are estimates of about four characters per token.
  </Step>
</Steps>

## Use the web app

Open [http://localhost:3000](http://localhost:3000) to paste a URL or drop a file. The file picker takes HTML files, e-mail, text and the other [formats PullMD reads](/guides/documents), and PDF and Office files when the MarkItDown sidecar is running. The result shows the Markdown, the extractor that produced it, and buttons to copy, download or share it. On a phone, install it as an app and share links to it straight from your browser.

### Advanced settings

The bar under the URL field has **Comments**, **Frontmatter**, **PDF OCR** (when the instance has OCR) and **Pull**. Open **Advanced** below it for the rest. Each setting matches an API parameter, and a value equal to the default isn't sent. A group or option shows only when the instance offers it, as `GET /api/config` reports.

| Group | Setting | Parameter | Notes |
| --- | --- | --- | --- |
| Reddit and Hacker News | **Depth**, **All** | `comment_depth` | `1` to `10`, default `3`. **All** sends `comment_depth=all`. Both are greyed out while **Comments** is off, and **Depth** while **All** is on. |
| | **Max. count** | `comment_limit` | Maximum number of top-level comments. Empty means no cap. |
| | **Describe images in posts** | `images` | Reddit only. Server default, on or off. Shown when the instance can describe embedded images. |
| YouTube | **Timecodes**, **Block length (s)** | `yt_timecodes`, `yt_chunk` | Shown when the YouTube tier is on. See [YouTube transcripts](/guides/youtube). |
| PDFs and documents | **Figures** | `pdf_images` | **Omit** (`strip`, default), **Describe** (`caption`) or **Include** (`hosted`). Works only with **PDF OCR** on. **Include** shows only when the instance [hosts figures](/guides/documents#hosted-figures). For an upload it also needs **Store uploads**; without it, the web app sends `caption`. |
| | **Store uploads** | `store` | File uploads only. Shown when the instance allows [stored uploads](/guides/documents#keep-an-upload). |
| Web pages | **Extractor** | `extractor` | Automatic, Readability, Trafilatura or Browser. Trafilatura and Browser show only when the instance runs that sidecar. An uploaded HTML file ignores Browser. |
| | **Browser rendering** | `render` | Automatic, **Force** (`force`) or **Skip** (`skip`). Shown when the instance runs the browser sidecar. |

The web app keeps these settings in your browser, not on your account. A non-default extractor, rendering or YouTube value skips the cache, and so do a depth other than `3`, **All**, **Max. count** and **PDF OCR**. The fetch then takes longer and replaces the cached copy of the URL, which is what its [share link](/guides/share-links) shows.

Closed, **Advanced** shows **n changed** when `n` settings that the instance offers and that currently apply differ from their defaults. **Reset** restores the defaults of this panel and leaves the toggles in the bar alone. **Fetch fresh** fetches the URL in the field once past the cache and replaces the cached copy. The choice itself isn't remembered.

Opening an entry from the history sends comments, depth, **All**, **PDF OCR** and figures, but not extractor, rendering, YouTube options, **Max. count** or image description. A depth other than `3`, **All** and **PDF OCR** still skip the cache and replace the cached copy. A link opened through the share target is a normal pull and sends every setting.
